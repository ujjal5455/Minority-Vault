# Bundled assets and licences

Every font, sound and image shipped in the APK, where it came from, and its licence.

## Fonts

| File | Font | Source | Licence |
|---|---|---|---|
| `designsystem/src/main/res/font/big_shoulders_display.ttf` | Big Shoulders Display (variable, wght 100–900) | [google/fonts `ofl/bigshouldersdisplay`](https://github.com/google/fonts/tree/main/ofl/bigshouldersdisplay) | SIL Open Font License 1.1, see [licenses/BigShouldersDisplay-OFL.txt](licenses/BigShouldersDisplay-OFL.txt) |
| `designsystem/src/main/res/font/instrument_sans.ttf` | Instrument Sans (variable, wdth and wght) | [google/fonts `ofl/instrumentsans`](https://github.com/google/fonts/tree/main/ofl/instrumentsans) | SIL Open Font License 1.1, see [licenses/InstrumentSans-OFL.txt](licenses/InstrumentSans-OFL.txt) |

The OFL allows bundling in apps, including commercial ones, as long as the licence travels with the font and the font isn't sold on its own.
